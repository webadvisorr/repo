# evrako — local run doc

Pure PHP 8 app (no Composer, no Node). Runtime pieces live outside the repo in `$HOME`.

## Reproduce the local artifacts a fresh checkout needs

1. **PHP 8.3 binary** — portable build at `$HOME/bin/php/php` (not on `PATH`).
2. **MariaDB 11.4 portable build** — unpacked at `$HOME/mariadb`, data dir `$HOME/mysql-data`.
   If the data dir is missing, initialise it once:
   ```
   $HOME/mariadb/bin/mariadb-install-db --no-defaults \
     --basedir=$HOME/mariadb --datadir=$HOME/mysql-data \
     --auth-root-authentication-method=normal > $HOME/mysql-init.log 2>&1
   ```
3. **App config** — `config/config.php` is generated by the installer (`install.php`) and is
   git-ignored. The existing checkout already has it (DB: `127.0.0.1:3307`, database `evrako_live`,
   user `root`, empty password). Copy the procedure, never the secret values, from the main checkout.

## Run the server

Start MariaDB (unix socket + TCP on 3307), then the PHP built-in server on port 3001:

```
export HOME=/workspace/homes/9e03ed61266af80267d81f50
mkdir -p $HOME/mysql-tmp
setsid $HOME/mariadb/bin/mariadbd --no-defaults --basedir=$HOME/mariadb \
  --datadir=$HOME/mysql-data --socket=$HOME/mysql-tmp/mysql.sock --port=3307 \
  --bind-address=127.0.0.1 --pid-file=$HOME/mysql-tmp/mysqld.pid \
  > $HOME/mysql-tmp/server2.log 2>&1 < /dev/null &

cd /workspace/chats/9e03ed61266af80267d81f50
setsid $HOME/bin/php/php -S 0.0.0.0:3001 -t . dev-router.php \
  > $HOME/php3001.log 2>&1 < /dev/null &
```

Wait until the socket answers (`mariadb --socket=$HOME/mysql-tmp/mysql.sock -uroot -e 'SELECT 1'`)
and `curl -s -o /dev/null -w '%{http_code}' http://127.0.0.1:3001/` returns `200`.

Preview hostname for this VM: `pv-9e03ed61266a-cdba9a66-06da-4b6e-9cb7-668a9d315293.style.dev`
(the hostname changes on every VM/restore — read the current one from the activation block and put it in
`config/config.php` → `app.url`; absolute `url()`/`asset()` links break otherwise.)
(bound to `0.0.0.0:3001`, exposed through the desktop Browser panel).
Health check with the preview Host header (the app also answers on 127.0.0.1):
```
curl -s -o /dev/null -w '%{http_code}\n' -H 'Host: pv-9e03ed61266a-cdba9a66-06da-4b6e-9cb7-668a9d315293.style.dev' \
  http://127.0.0.1:3001/          # 200
```
Logs: `$HOME/php3001.log` (PHP dev server), `$HOME/mysql-tmp/server2.log` (MariaDB).
No env files, no Composer/Node install step — everything the server needs is in `$HOME` plus the
git-ignored `config/config.php` already present in this worktree.

## Hatırlatma motoru (Faz 3) elle çalıştırma

CLI (günlük cron görevinin yerel karşılığı):
```
$HOME/bin/php/php cron/reminders.php        # çıkış kodu 0 = temiz, 2 = gönderim hatası var
```
Web cron (SSH'sız hosting için uygulama rotası):
```
TOKEN=$($HOME/bin/php/php -r "require 'app/bootstrap.php'; echo App\Core\Config::get('security.cron_token','');")
curl -s "http://127.0.0.1:3001/cron-hatirlatma?token=$TOKEN"
```
Panelden: `/yonetim/sistem` → "Cron'u şimdi çalıştır", `/yonetim/bildirimler` → "Kuyruğu işle" / "Tara".
SMTP gerçek gönderim testi için `.freebuff/e2e_reminders.sh` kendi yerel alıcısını başlatır:
`.freebuff/smtp-sink.php <port> <çıktı klasörü> <mesaj sayısı> <zaman aşımı>` (paket 2525 kullanır ve
ayarları `127.0.0.1:2525` yapıp sonunda eski değerlere geri yazar). Elle denemek istersen:
`$HOME/bin/php/php .freebuff/smtp-sink.php 2525 /tmp/smtp-sink 1 120 &`

Note: `config/config.php` -> `app.url` must match the current preview hostname, because `url()`/`asset()`
build absolute URLs. `asset_version` is bumped when CSS/JS changes so browsers refetch.

## Canlı ziyaretçi, mesajlar ve destek
- **Ziyaretçi sayacı**: `index.php` her sayfa görüntülemesinde `visitor_sessions` tablosunu günceller

## Site asistanı (Gemini)
Yönetim paneli → `Ayarlar → Site Asistanı (Gemini)`:
1. https://aistudio.google.com/app/apikey adresinden API anahtarı oluşturun.
2. Anahtarı ve modeli girin (varsayılan `gemini-3.6-flash`; hızlı/ekonomik alternatifler `gemini-2.5-flash`, `gemini-3.1-flash-lite`).
   Ölçüm (2026-10-21, aynı anahtar): `gemini-3.6-flash` ~1,0 sn · `gemini-3.5-flash` ~1,3 sn · `gemini-2.5-flash` ~0,6 sn ·
   `gemini-3.8-flash` ve `gemini-3.7-flash` **yanıt vermedi** (45-90 sn sonra 0 byte). Kullanılamayan modelde asistan
   "Şu anda yanıt veremiyorum" der ve `storage/logs/<tarih>.log` içine `Site asistanı bağlantı hatası` yazar.
3. "Site asistanını göster" açık olsun ve kaydedin. Anahtar girilene kadar widget sitede görünmez.

Asistan yalnızca site/paket/evrak konularında yanıt verir; fiyat uydurmaz, evrakların ücretsiz olduğunu
ve iki paket modelini bilir. Anahtar sunucuda `settings` tablosunda tutulur, tarayıcıya gitmez.
Oturum başına 10 dakikada 15 mesaj sınırı vardır. İstek: `POST /asistan` (CSRF + JSON yanıt).

`App\Services\SiteAssistant::reply()` isteği `thinkingConfig.thinkingBudget = 0` ile gönderir: sohbet için
"düşünme" adımı gereksizdir ve kapatılmazsa yanıt token bütçesini tüketip cümle ortasında kesilir
(`finishReason=MAX_TOKENS`). cURL zaman aşımı 45 sn'dir.

Elle kontrol: `.freebuff/e2e_site_assistant.sh` (anahtarsız ve geçersiz anahtarlı yolları doğrular;
kayıtlı anahtarı geçici olarak boşaltır ve çıkışta geri yükler).
Gerçek (canlı) yanıt testi — anahtar `settings` tablosunda kurulu olmalı:
```
J=/tmp/asst.txt; rm -f $J
curl -s -c $J -b $J http://127.0.0.1:3001/ -o /tmp/h.html
T=$(grep -o 'name="_token" value="[^"]*"' /tmp/h.html | head -1 | sed 's/.*value="//;s/"$//')
curl -s -c $J -b $J -X POST --data-urlencode "_token=$T" \
  --data-urlencode "message=Merhaba, paketler ve fiyatlar neler?" http://127.0.0.1:3001/asistan
```
Beklenen: `{"ok":true,"reply":"..."}` ve yanıtta 490 / 392 / 343 TL + "6 Ay Ücretsiz Deneme" geçer, evrakların
ücretsiz olduğu söylenir. Anahtar tarayıcıya gitmez; yalnızca sunucuda `settings.site_assistant.api_key` alanında durur.

## Cihaz bildirimleri (Web Push)
- Göç: `2026_10_22_013_web_push.sql` (`push_subscriptions`, `push_queue`), `2026_10_22_014_brand_evrako.sql` (marka adı). Panelden **Sistem → Güncellemeleri uygula** ile çalıştırılır.
- Akış: müşteri `/panel/bildirimler` → “Cihaz bildirimleri” kartı → “Bu cihazda bildirimleri aç”. Tarayıcı izni + VAPID aboneliği `push_subscriptions`'a yazılır; `users.notify_push` işaretlenir.
- Bildirim üretimi: `InboxService::create()` her panel bildirimini `PushService::queueFromNotification()` ile kuyruğa ekler (duyuru, hatırlatma, hesap bildirimi). `PushService::process()` kuyruğu işler; cron (`CronService::runDaily`) 60, duyuru gönderimi 15, panel düğmesi 60 kayıt işler.
- VAPID anahtarları ilk `PushService::publicKey()` çağrısında üretilir ve `settings.push.vapid_public` / `push.vapid_private` alanlarında tutulur. Özel anahtar tarayıcıya gitmez.
- Service worker: `GET /sw.js` (`assets/js/sw.js`, `Service-Worker-Allowed: /`). HTTPS zorunludur (localhost istisna); iPhone/iPad’de iOS 16.4+ ve “Ana Ekrana Ekle” gerekir.
- Test: `.freebuff/e2e_push.sh` — yerel alıcıya (`http://127.0.0.1:3112`) gönderir, RFC 8291 gövdesini abonelik özel anahtarıyla çözer ve VAPID ES256 imzasını doğrular. Yardımcılar: `.freebuff/push-receiver.php`, `.freebuff/push-call.php`.
- Not: yerel taşınabilir PHP’de openssl yapılandırması yoksa anahtar üretimi başarısız olur; testleri `OPENSSL_CONF=/etc/ssl/openssl.cnf` ile çalıştırın. Standart hostingde gerekmez.
